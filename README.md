# Oracle EBS AI Chatbot

Proof of Concept demonstrating a secure, read-only AI chatbot for Oracle EBS using:

- Oracle APEX
- FastAPI
- Local LLM (Ollama/vLLM)
- RAG
- Oracle Database
- PL/SQL

## Architecture

APEX → FastAPI → Chatbot → Business Tools → Oracle EBS
